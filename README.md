# mae-meow-website
Mae Meow Thai Noodle Shop Website

Project Overview
This project is a responsive website for Mae Meow Thai Noodle Shop, location in Muak Lek, Saraburi, Thailand.
The website introduces the shop, its food, and the cooking knowledge shared by the shop owner.

Project Purpose
The purpose of this project is to introduce Mae Meow Thai Noodle Shop and preserve its food knowledge through interviews, photographs, and website content.

Technologies
.HTML
.Tailwind CSS
.JavaScript

Planned Website Pages
1.Home page
2.About Us
3.Our Menu
4.Ingredients
5.Our Knowledge
6.Contact

Project Goal
To create a user-friendly and responsive website and works on mobile phones and desktop computer.
